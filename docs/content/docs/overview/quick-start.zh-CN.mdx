# 快速开始

## 部署（纯静态，无需后端）

项目是纯静态前端，模型请求由浏览器直连各自网关，不需要数据库或服务端。最省事的是 Docker 一条命令：

```bash
docker run -d --name infinite-canvas -p 3000:3000 --restart unless-stopped \
  ghcr.io/CR-c/vpapi-canvas:latest
```

打开 `http://本机IP:3000`。更多方式（Render / Vercel / 用 AI 部署）见根目录 `DEPLOY.md`；想用 Codex / Claude Code / Cursor 帮你部署时，直接把 `DEPLOY.md` 里的提示词段落发给它即可。

## 填一次 Key 就能用

1. 打开页面右上角**配置**。
2. 在「一步接入 vpapi」里粘贴你的 API Key，点「接入并拉取模型」。
3. 画布自动导入该 Key 下的全部生图 / 视频 / 文本模型并设好默认项。

之后即可直接开始文生图、图生图、文生视频、图生视频和对话助手。

## 本地开发

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas/web
bun install
bun run dev
```

访问 `http://localhost:3000`。

## 换成你自己的网关

配置里可以新增任意渠道：协议选 OpenAI / Gemini 兼容即可，模型通过「选择模型 → 拉取」自动导入并按网关能力标签归类；vpapi 渠道只是预置好的一个。

## 说明

- 当前画布项目和“我的素材”主要保存在浏览器本地，WebDAV 同步需要用户自行配置。
- AI API Key 保存在浏览器本地，由前端直接请求网关，不会上传到画布服务器。
